> I build tools for freight operations because "scroll through yesterday's group chat" is not a workflow.

The flow I keep unblocked:

`request → documents → rates → schedules → shipments → follow-up`

## Current focus 🧭

- Operational dashboards and data workflows for logistics teams.
- AI-assisted document intake, rate and schedule retrieval, routing, and human review.
- Supply-chain research in an Indonesian export-import context.
- Small evals before AI tools are trusted with real work.

Most production work stays private because it touches customer, shipment, or internal operating data. Public repositories are mostly learning notes, experiments, and selected tools.
